The Problem

  • Students enter lab sessions underprepared despite manuals and videos
  • Instructors discover knowledge gaps during sessions - too late to fix
  • Time wasted repeating fundamentals that should have been mastered before arrival

What Changes

  • Resource distribution becomes Readiness assurance
  • AI explains, but code decides
  • Critical safety failures block readiness regardless of score
  • System works without AI - assessment functions if AI is down

Three Principles

1. AI is Not the Authority LLM cannot determine readiness status. D1 database applies rules deterministically.
2. Critical Override A safety-critical failure = not ready, regardless of overall score percentage.
3. Works Without AI Assessment, scoring, and readiness determination function even if Workers AI is unavailable.

User Journeys & Interrelation

2 / 2

Learner Journey

  1. Dashboard - View assigned modules, track progress
  2. Module Overview - Read objectives, prerequisites, compliance notice
  3. Guided Activity - Step through content with adaptive checkpoints min read time auto-loop on failure
  4. AI Coach - Ask questions, get RAG-powered answers with cited sources
  5. Assessment - 5 questions, server-scored, critical Qs can block Ready status
  6. Readiness Report - Score breakdown, competency analysis, remediation actions

Instructor Journey

  1. Cohort Insights - Readiness distribution, competency averages
  2. Step Friction - Which steps cause retries, time bottlenecks
  3. Module Configuration - Thresholds, weights, critical flags
  4. Content & AI - Upload files, auto-generate questions, approve
  5. Checkpoint Approval - Review, approve/reject/edit generated Qs
  6. Intervention List - Prioritised learners needing help

How They Connect

Learner completes assessment → Readiness Engine scores deterministically → Result feeds instructor dashboard → Instructor sees who needs intervention before the session
"The learner proves readiness. The instructor gains visibility. The system ensures no one enters unprepared."
